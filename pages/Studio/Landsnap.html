Version 2.0.0 / pending Fab approval

The placement pass.
Rebuilt around your flow.

Submitted for Fab review on September 16, 2026. Automatic publication follows approval. From the first prop to a whole selection, v2 brings placement, contact review, and repair into one dockable workspace.

01 / AutoSnap

One global placement mode

Use the checkable AutoSnap toolbar toggle to settle eligible placed or edited actors after their changes finish—without per-object enrollment.

02 / Terrain fitting

Uneven ground. Considered.

Rigid actors fit against real support edges. Contact checks keep unresolved placements visible in Needs Review, ready for your next pass.

Progressive repair

Exact-target verification sends unresolved placements to Needs Review, where Repair Current and Repair All test deterministic candidates one editor tick at a time.

Your tools. In one place.

Dock placement controls, review, repair, and repeatable Scatter and Domino calibration layouts beside your viewport. Rebind your shortcuts live.

Read The v2 Workflow

Core workflow

From selection to settled in three steps

Use the default contract for fast passes. Tune only when the scene asks for more control.

Step 01

Select

Choose actors, particle systems, spline components, or spline mesh components.

Step 02

Choose AutoSnap or Snap Selected

Enable global AutoSnap for eligible editor changes, or run the one-shot unified Snap Selected action when you want a deliberate pass.

Step 03

Review and refine

Use Needs Review for exact-target exceptions, then tune alignment, Z offset, trace distance, or size tiers only if the scene needs it.

Predictable by design: terrain and tagged-surface modes are mutually exclusive. Tagged placement is surface-based, not free-form stacking.

Documentation

Start in minutes. Tune only when needed.

The common path is short. Open a section when you need the deeper placement contract.

01Installation and activationPlugin setup
  1. Copy the LandSnap folder into your project's Plugins/ directory.
  2. Open the project and enable LandSnap in Edit -> Plugins if prompted.
  3. Restart Unreal Editor and allow the editor module to rebuild when required.
  4. Open Window -> LandSnap Panel to dock actions and live settings beside your normal editor tools.

Built for Unreal Engine 5.8 on Win64. LandSnap is editor-only and does not affect packaged builds.

03Actors, particles, and splinesPlacement behavior

Actors

Choose pivot or bounds-bottom placement, optional normal alignment with preserve-yaw, normal push, max slope, Z offset, and configurable trace distances.

Particles

Niagara and Cascade actors use stable emitter-pivot placement by default. Rotation is preserved unless particle normal alignment is explicitly enabled.

Splines

Snap spline points and spline mesh endpoints individually, with optional surface-normal up-vector alignment and point-count limits for long splines.

04Terrain and tagged-surface modesSurface policy

Only Terrain Surfaces

Allows Landscape and reflected UE 5.8 Mesh Terrain actors and components as valid snap targets.

Only Tagged Surfaces

Requires matching actor or component tags. Add allow tags, ignore tags, and choose where tag checks are performed.

These modes are mutually exclusive. Tagged mode uses Visibility trace fallback; disabling that fallback also disables tagged-surface mode.

05Hinge fitting and Needs ReviewUneven terrain

Adjacent-edge hinge fitting

For rigid actors, LandSnap evaluates real neighboring bottom edges—not diagonals—then searches balanced and three-corner support for the strongest supported pose.

Review classifier

Exact-target verification recognizes seated four-corner and bounded penetrating three-corner support while keeping one-edge-only, floating, and split-terrain misses reviewable.

Progressive repair

Needs Review can Repair Current or Repair All with one unique deterministic candidate per editor tick. Published winners are freshly audited; stopped or exhausted actors return to their immutable baseline.

06Calibration, experimental Mesh Terrain, and limitsSetup

Calibration

Setup -> Calibration provides repeatable Scatter and Domino layouts. Compare placement across size tiers, exercise Snap Selected, and clean up only the owned calibration actors.

Experimental Mesh Terrain

Setup -> Experimental Settings -> Enable Mesh Terrain (Experimental) is off by default. It gates optional non-destructive deformation only; ordinary Mesh Terrain snapping remains available when it is off.

Very thin meshes, extreme slopes, missing simple collision, or highly concave targets can still need manual tuning. LandSnap favors predictable placement over physical simulation.

Design intent

Fast and predictable—not simulated perfection

Terrain, collision, and asset bounds vary. LandSnap uses conservative, size-aware placement heuristics so the common case stays quick, undoable, and easy to reason about.

  • Missing simple collision can reduce trace reliability.
  • Extreme slopes and highly concave geometry may need tuning.
  • Large selections naturally require more traces.
